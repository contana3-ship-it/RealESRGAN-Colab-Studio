This project uses publicly released RealESRGAN_x4plus model weights and
reimplements an RRDBNet architecture compatible with the official weights.
References:
- https://github.com/xinntao/Real-ESRGAN (BSD 3-Clause)
- https://github.com/XPixelGroup/BasicSR (Apache-2.0)
Please review both projects' current license and model-weight distribution
terms before redistribution. Weights are downloaded from the official release,
not bundled inside this repository.
